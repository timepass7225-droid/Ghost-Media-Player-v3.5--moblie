# Ghost Media Player — Mobile edition (Android) v3.7

A separate phone edition, laid out like a classic mobile media player. The laptop version is untouched.

## What is different from the laptop version
- **Layout:** top bar (title, search, add files) + bottom navigation **Video / Audio / Radio / Lyrics / More** (Effects, Themes, Settings, About).
- **Lists:** Video and Audio tabs with big rows; a **mini player** sits above the navigation while something plays - tap it for the full player.
- **Full player:** seek bar on top, two rows of big keys (shuffle, previous, play, next, loop / speed, boost, lyrics, stop, fullscreen). Volume = phone's hardware buttons.
- **Removed on phone:** DJ Mode and the "Advanced UI Design" picker.
- **Themes (More > Themes):** 18 colour themes (default "Classic Orange"; new: AMOLED Black, Rose, Lavender, Gold, Coffee, Cloud) + 6 **Music player looks** (Classic, Vinyl, AMOLED, Poster, Neon Ring, Minimal) + control-bar styles.
- **Kept:** Radio, Lyrics, Effects, Settings, shuffle/loop/speed, lock-screen controls.
- **Lyrics on video:** while a video plays, the current .lrc line is shown on the picture like subtitles. Put `video.lrc` next to `video.mp4` and select both when opening, or tap the "Lyrics" key in the player to pick a file.
- Back button: player -> list -> minimise (music keeps playing).

## What is new in 3.7 (smoothness + logo)
- **No more flicker when a video starts:** the page no longer resizes while the video opens, and the picture stays hidden until its first frame is ready, then fades in (js/perf.js, css/perf.css).
- **Less work while playing:** no infinite animation/drop-shadow on top of the picture, equaliser animates with transform only, the seek bar paints at most once per frame, track change no longer rebuilds the whole list, long lists only lay out visible rows, audio engine runs with a bigger buffer (`latencyHint: "playback"`), video is no longer pre-buffered whole.
- **Performance mode (More > Settings > Performance):** Auto (default) / Smooth (Lite) / Full. Lite removes shadows, transitions and decorative animation. Auto turns Lite on for phones with little RAM / few cores, and also switches it on by itself if a video drops many frames.
- **Start-up fix:** the app now opens on the library list (before, it could start on the empty player without the bottom bar).
- **Logo:** launcher icon (square, round, adaptive + Android 13 themed icon) and splash screen are generated from `build/icon_512.png` and applied automatically by the GitHub build (`scripts/apply-android-resources.js`). To change the logo: replace `build/icon_512.png`, run `python3 scripts/make-icons.py`, commit `resources/`.

## Build the APK on GitHub
See GITHUB-APK-GUIDE.md. Short version: put the contents of this folder in a GitHub repo, Actions -> "Build Android APK" -> Run workflow -> download the artifact.

## Build locally
```
npm install
npm run build
npx cap add android      # once
npx cap sync android
cd android && ./gradlew assembleDebug
```
`www-src/` is the readable source, `www/` is generated by `npm run build`. Edit www-src, never www.

## Not verified here
Everything is tested in headless Chromium (`npm test`, plus `python3 tests/test_smooth.py`), but there was no Android SDK / real phone in the sandbox: the APK build itself, the icon/splash on a real launcher and the real-device smoothness have to be checked on your phone. Heavy videos that the phone cannot hardware-decode (e.g. 4K HEVC in some WebViews) can still stutter, because the player uses the system WebView decoder.
